VML Company Trip trên Netlify và Supabase

Khoảng 30 phút, miễn phí. Supabase lưu dữ liệu (nhân vật, giường, deal, thách đấu), Netlify đưa trang game lên mạng. Làm lần lượt từ A đến F.

Gói này có gì

index.html
Game. Tự nhận biết online hay offline.
config.js
Dán địa chỉ và khoá Supabase. Chỉnh tiền khởi đầu, độ dài ngày.
supabase-shim.js
Lớp kết nối game với Supabase. Không cần sửa.
admin.html
Mở ngày mới, kết thúc ngày, xem người chơi.
supabase-setup.sql
Tạo bảng, hàm và luật bảo mật. Chạy một lần.
Chưa điền config.js thì game vẫn chạy offline với 16 nhân viên giả lập. Bạn có thể đưa lên Netlify trước để xem thử, rồi bật Supabase sau.

A. Chuẩn bị

3 phút
  1. Tạo tài khoản GitHub. Đăng nhập Supabase và Netlify bằng GitHub là nhanh nhất, và nhờ đó Claude cập nhật game được (phần F).
  2. Giải nén gói vml-trip-netlify.zip. Bạn sẽ có thư mục vml-trip-netlify với 5 file ở trên.

B. Tạo database Supabase

10 phút
  1. Vào supabase.com/dashboard → đăng nhập bằng GitHub → New project. Tên: vml-trip. Database Password: bấm Generate và lưu lại. Region: Southeast Asia (Singapore). Bấm Create new project và chờ khoảng 2 phút.
  2. Menu trái Authentication → Sign In / Providers → bật Allow anonymous sign-ins → Save changes. Người chơi không cần email hay mật khẩu, máy của họ được nhớ tự động.
  3. Vẫn trong Authentication → Rate Limits → tìm dòng giới hạn cho anonymous users (đăng nhập ẩn danh), đổi từ 30 thành 300 → Save.
  4. Menu trái SQL Editor → New query → mở file supabase-setup.sql, copy toàn bộ và dán vào → bấm Run. Thấy Success. No rows returned là xong.
  5. Bấm Connect ở thanh trên cùng, hoặc vào Project Settings → API Keys. Copy Project URL (dạng https://abcd1234.supabase.co) và khoá anon public (một chuỗi rất dài).
  6. Mở config.js bằng trình soạn văn bản (Mac: TextEdit → Format → Make Plain Text; Windows: Notepad). Dán Project URL vào url và khoá anon vào anonKey, giữ nguyên dấu ngoặc kép. Lưu file.
Bước B3 rất quan trọng. Mặc định Supabase chỉ cho 30 lượt đăng nhập ẩn danh mỗi giờ trên mỗi địa chỉ IP. Cả công ty dùng chung WiFi văn phòng sẽ bị chặn từ người thứ 31.
Không bao giờ dán khoá service_role (hoặc secret) vào config.js. Chỉ dùng khoá anon public.

C. Đưa game lên Netlify

5–10 phút

Cách 1: Kéo thả (nhanh nhất)

  1. Vào app.netlify.com và đăng nhập bằng GitHub. Phải đăng nhập trước; trang đưa lên khi chưa đăng nhập sẽ tự xoá sau khoảng 1 giờ.
  2. Bấm Add new site (hoặc Add new project) → Deploy manually → kéo thả cả thư mục vml-trip-netlify vào ô tải lên.
  3. Netlify cho bạn một địa chỉ ngẫu nhiên. Vào Site configuration → Change site name, đặt tên như vml-trip-2026 để có link https://vml-trip-2026.netlify.app.
  4. Mỗi lần sửa file, vào tab Deploys và kéo thả lại cả thư mục.

Cách 2: Qua GitHub (để Claude cập nhật tự động)

  1. Vào github.com/new → tên vml-trip → Public → Create repository → uploading an existing file → kéo thả 5 file → Commit changes.
  2. Netlify → Add new site → Import an existing project → GitHub → chọn repo vml-trip. Để trống Build command, Publish directory ghi . → Deploy.
  3. Từ giờ mỗi lần file trên GitHub thay đổi, Netlify tự đưa bản mới lên sau khoảng 1 phút.
Mở link game. Dòng dưới nút VÀO RESORT ghi "Bản online · người chơi thật" là đã kết nối Supabase thành công.

D. Cấp quyền admin cho bạn

3 phút
  1. Mở https://TEN-SITE.netlify.app/admin.html → bấm SAO CHÉP để copy Mã của bạn.
  2. Supabase → SQL Editor → New query → dán dòng dưới, thay mã của bạn vào → Run. 
    insert into public.admins(uid) values ('DAN-MA-CUA-BAN') on conflict do nothing;
  3. Tải lại admin.html. Khi thấy "Bạn là admin", bấm BẮT ĐẦU NGÀY MỚI. Đồng hồ game của mọi người bắt đầu từ 08:00.
Mở admin.html và game trên cùng một trình duyệt thì mã admin cũng là nhân vật của bạn. Muốn chơi bằng nhân vật khác, dùng trình duyệt khác hoặc cửa sổ ẩn danh.

E. Vận hành trong ngày trip

  1. Gửi link cho nhân viên. Mỗi máy tạo nhân vật một lần. Lần sau mở lại, game nhận ra họ và hiện "Chào mừng trở lại".
  2. Muốn làm lại nhân vật: nút NV góc phải → TẠO NHÂN VẬT MỚI → bấm lần nữa để xác nhận.
  3. Mỗi đợt chơi, admin bấm BẮT ĐẦU NGÀY MỚI: làm trống giường, đồng hồ về 08:00. Ví tiền mọi người được giữ nguyên.
  4. Đổi luật trong config.js rồi đưa lên lại: startMoney (tiền cho người chơi mới, đang 500.000), dayMinutes.

F. Kết nối Claude để cập nhật nhanh

  1. Làm theo Cách 2 ở phần C để game nằm trên GitHub.
  2. Trên claude.ai, kết nối GitHub và cho phép truy cập repo vml-trip. Rồi nhắn Claude: "Repo của tôi là TEN-GITHUB/vml-trip". Claude sửa code, đẩy lên GitHub, Netlify tự cập nhật trang.
